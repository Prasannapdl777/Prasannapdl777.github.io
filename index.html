What I Do

  • Clean and merge large daily climate and streamflow records covering 30+ years
  • Measure how rainfall, temperature, solar radiation, and vapour pressure affect streamflow
  • Test results with significance tests to separate real signals from random noise
  • Build Python scripts that process all basins and save organized outputs
  • Build machine learning models for streamflow prediction
  • Build numerical rainfall-runoff models and calibrate them

My Projects

  • Transfer Entropy and Mutual Information on CAMELS: Analyzed 671 basins to understand how climate variables affect streamflow at different time delays (1-30 days).
  • Machine Learning for Streamflow: Built and compared Linear Regression, Random Forest, and LSTM models for daily streamflow prediction.
  • Numerical Rainfall-Runoff Model: Built a model in Python with soil moisture, groundwater, and runoff paths. Improved performance from NSE 0.18 to NSE 0.40.
  • Transfer Entropy vs SHAP: Tested two model interpretation methods to see which correctly finds the delay between rainfall and streamflow.
